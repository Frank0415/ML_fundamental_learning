# 09 — Qwen2.5-VL: 更强视觉感知与训练稳定性

## 一句话总结

Qwen2.5-VL 在 Qwen2-VL 的架构基础上，通过更强的视觉编码器、更大规模的高质量训练数据和更稳定的训练策略，全面提升视觉感知能力，尤其在文档解析、图表理解和视频理解任务上取得显著进步。

## 关键 Idea

### 1. 视觉编码器增强

Qwen2.5-VL 使用了更大、更强的 ViT 视觉编码器。相比 Qwen2-VL 的 ViT，2.5 版本在以下几个方面做了增强：

- **更大的视觉编码器参数**：ViT 参数量增加，可以捕捉更细粒度的视觉特征。
- **更好的预训练**：视觉编码器在更高质量、更多样化的图文数据上预训练，对 OCR 和文档排版的理解能力更强。
- **多尺度训练**：训练中使用多种分辨率组合，让模型对不同尺寸的输入更加鲁棒。

### 2. 训练数据质量与规模

Qwen2.5-VL 训练数据的质量提升是其能力增强的关键因素：

- **文档数据**：引入大量 PDF、Word 文档、PPT 截图等办公文档，并保留了原始排版信息（bounding box、阅读顺序等）。这让模型在文档 QA 和结构化信息提取任务上表现优异。
- **视频理解数据**：增加视频描述、视频 QA 和时序定位数据，使视频理解能力显著提升。
- **多语言数据**：涵盖中英之外的多种语言，提升跨语言 OCR 和翻译能力。
- **训练稳定性**：改进数据采样策略和 loss 函数，减少训练不稳定和崩溃。

### 3. 架构继承与改进

Qwen2.5-VL 继承了 Qwen2-VL 的三段式架构（ViT → VL Adapter → LLM）和动态分辨率 + M-RoPE。架构上与 Qwen2-VL 高度一致，改进集中在数据和训练上：

- 更大的 ViT 编码器（视觉宽度增强）。
- VL Adapter 的投影效率优化（更少的 visual token per image 但信息量更高）。
- LLM 基础模型升级（更好的文本能力底座）。

### 4. 与 Qwen3-VL 的关系

Qwen2.5-VL 是 Qwen3-VL 的 **"能力基线"**。Qwen3-VL 的目标是在保持 Qwen2.5-VL 同等多模态能力的前提下做效率优化（更小的模型、更快的推理）。因此 Qwen2.5-VL 的文档解析、视频理解等高级能力是 Qwen3-VL 的上界参考。

## 与本项目的关联

Qwen2.5-VL-3B 是我们 显存的 **稳定 fallback**，当 Qwen3-VL-4B 因显存或兼容性问题无法加载时回退到它。理解 Qwen2.5-VL 的架构继承关系，有助于我们在不同模型切换时做正确的 `max_pixels` 和 visual token 预算调整。Qwen2.5-VL 对文档的强理解能力也意味着我们的 token pipeline 在构造测试用例时应该考虑文档类图像。
