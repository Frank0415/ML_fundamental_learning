🔍 关键发现

当问题 (文本) 不同时, 即使图像相同, 三种策略均正确判定为 miss。这是因为文本 token IDs 本身就是 key 的一部分。

此场景说明: text-only cache 的"假阳性"风险仅限于 文本相同但视觉内容不同 的情况, 而不会在视觉相同但文本不同时误判。
