🔍 关键发现

text-only prefix cache 在多模态下不安全。

当两个请求使用相同文本但不同图像时, 策略 A (仅 hash 文本) 错误地判定为命中 (false_hit), 导致 KV cache 被复用给不匹配的图像上下文。

策略 B 通过纳入图像 SHA-256 避免了此问题。策略 C 在此基础上进一步将图像处理参数 (resize/grid/layout/order) 纳入 key, 提供最严格的 cache 安全性。

建议: 多模态推理中, 前缀 cache 的 key 必须至少包含图像内容的 hash (策略 B), 理想情况下应包含完整的图像处理元数据 (策略 C)。
