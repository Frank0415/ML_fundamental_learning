01 — 任务总览：本项目做什么，不做什么

项目定位

本项目是一个现代扩散模型推理学习与实现项目，位于 diffusion/ 子目录内，与旧 minivLLM/ 引擎完全隔离。

核心目标：从零理解现代扩散模型的推理路径，落地一个最小但完整的 diffusion_engine/，并在 12GB RTX 5070 Ti 上跑通至少一个真实 reference inference。全程中文文档，纯静态 HTML 知识库，不做生产部署。

四个维度

维度目标状态
理解通过论文卡片、学习笔记、静态知识库，系统建立对 rectified flow、DiT/MMDiT、文生图/文生视频推理数据流的认识完成
实现从零构建最小 diffusion_engine/，覆盖 scheduler、rectified flow、DiT transformer block、text conditioning、pipeline、memory manager完成
运行12GB RTX 5070 Ti 上至少跑通一个真实文生图 reference inference；视频小规格尝试并如实记录 blocker脚手架就绪，环境未跑通
优化设计并运行 prompt cache、latent buffer、scheduler benchmark、CFG batching、attention memory、VAE tiling 对照实验完成

为什么不从老 DDPM/U-Net 学起

本项目有意识地跳过了"从 DDPM/U-Net 入门"的传统学习路线，直接进入现代范式。这不是投机取巧，而是一个明确的技术决策：

  1. 工业界已全面转向：2024 年后的主流模型（SD3、FLUX、Sana、CogVideoX、Wan2.1、HunyuanVideo）全部基于 rectified flow + DiT/MMDiT 范式。DDPM + U-Net 是 2020-2022 的历史产物，学习它会增加大量与当前实践无关的概念包袱（比如 predicting noise vs predicting velocity、discrete vs continuous timestep、U-Net skip connection 的特定设计）。
  2. 概念更统一：rectified flow 在理论上更简洁——一条从噪声到数据的直线路径（或接近直线的路径），配合 ODE solver 完成采样。这比 DDPM 的 denoising score matching + Langevin dynamics 组合更容易建立直觉，也更贴近 LLM 领域的 "single forward pass per step" 风格。
  3. 与系统优化直接相关：DiT 的 full attention 在高分辨率下产生 O(N²) 瓶颈，这正是扩散推理优化的核心战场。老 U-Net 的卷积式注意力不会暴露这个问题的严重程度，学 U-Net 无法为后续的 attention memory benchmark 提供足够的动机。
  4. 时间效率：6 周时间内，如果先花 2 周学 DDPM/U-Net，那留给现代架构和系统优化的时间只剩 4 周，不够用。直接从现代范式切入，每样学一点就能看到整体画面。

最终成果是什么

本项目在 6 周内产出了以下完整交付物集群：

知识库 (docs/)

  • 12 个中文静态 HTML 页面（01-12），覆盖任务总览、引擎审计、推理背景、rectified flow、DiT 架构、SD3/FLUX/Sana 模型、视频架构、视频模型、系统优化、最终成果说明
  • 纯静态，零外部依赖（无 CDN、无 webfont、无 npm），file:// 协议可打开

学习资料 (learning/)

  • 10 篇英文论文/模型卡的中文阅读卡片（papers/01-10）
  • 10 篇中文学习笔记（notes/01-10），覆盖环境审计、复用决策、数据流、scheduler 设计、DiT shape 系统、CFG、prompt cache、latent buffer、视频 latent、参考源码走读

自写引擎 (diffusion_engine/)

  • core/scheduler.py：Euler + rectified flow sampler，支持 image (B,C,H,W) 和 video (B,C,T,H,W)
  • core/rectified_flow.py：矢量场构造 + ODE 积分
  • core/timestep_embedding.py：sinusoidal + linear timestep embedding
  • core/attention.py：full attention（非 causal），支持 self-attention 和 joint attention
  • core/transformer_block.py：AdaLN-Zero modulation
  • core/dit.py：完整 DiT forward（patchify → blocks → unpatchify）
  • core/text_conditioning.py：toy text encoder + prompt embedding cache 接口
  • core/pipeline.py：6 步主循环（prompt→encode→init→denoise→CFG→scheduler→decode）
  • core/memory_manager.py：latent buffer 预分配、ping-pong swap、显存统计
  • core/vae_stub.py：toy VAE encode/decode（含 tiling 支持）
  • 36 个 pytest 测试（覆盖 scheduler、rectified flow、DiT shapes、pipeline smoke）

实验 (experiments/)

  • toy_rectified_flow/：toy vector field 仿真 + trajectory 可视化
  • toy_dit_inference/：最小 DiT denoising loop
  • reference_image_inference/：3 个真实模型脚手架（Sana/SD3/FLUX）+ memory profiler
  • reference_video_inference/：3 个视频模型脚手架（CogVideoX/Wan/LTX）+ blocker 记录
  • diffusion_inference_optimization/：6 个系统优化对照实验

报告 (reports/)

  • engine_inventory.md：旧引擎 14 模块逐一审计（515 行）
  • week_1.md ~ week_6.md：6 周进度周报
  • final_report.md：最终报告，回答 5 个核心问题

本页结论

本项目是一个面向现代扩散模型的推理学习项目，不走 DDPM/U-Net 旧路线，直接从 rectified flow + DiT/MMDiT 范式切入。6 周产出包括 12 页 HTML 知识库、10 篇笔记、10 篇论文卡片、一个最小但完整的 diffusion_engine/、5 组实验目录、6 份周报和一份最终报告。真实 reference inference 因远程 GPU 环境未就绪而阻塞，脚手架已完整就绪。

和我的 diffusion_engine 的关系

本页不实现任何代码。它是整个项目的"用户手册首页"——告诉读者这个项目是做什么的、为什么这样做、产出了什么。所有技术细节（scheduler 怎么设计、DiT shape 怎么流转、CFG 怎么做）都在 02-11 各页中展开。本页的价值在于提供全局视图，帮助读者判断"这个项目对我有没有用"以及"应该从哪一页开始读"。
