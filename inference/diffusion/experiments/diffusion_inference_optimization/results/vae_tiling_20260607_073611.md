## 设计说明：VAE Tiling 是什么

**工作原理**: VAE tiling 不是 torch.compile 或 flash-attn 等价物。它是显式的 chunk decode：将 latent/像素切分成多个 tile，分别做 VAE decode，最后拼接回完整图像。tile 之间添加 overlap 区域，用线性 blending 消除边界接缝。

**适用场景**: 适用场景：高分辨率（>= 1024×1024）VAE 解码 OOM 时。12GB VRAM 预算下，tiling 几乎总是必要的。尤其是文生视频，原始 latent (T, C, H, W) 一次性 decode 极易 OOM。

**限制**: VAE tiling 增加总计算量（overlap 区域重复计算）。典型开销：overlap=4 latent pixels → 额外 10–20% 计算量。对推理速度的影响取决于 GPU 的 compute-bound vs memory-bound 特性。

## 关键结论

> VAE tiling 是 12GB VRAM 下高分辨率扩散推理的必备技术。推荐 tile 大小：1024² → 64×64 latent tile；2048² → 32×32 latent tile。tile 大小的选择取决于：目标 VRAM 预算 vs 可接受的额外计算量。★★★ VAE tiling 不是 torch.compile 或 flash-attn 等价物，是显式 chunk decode + overlap blending。

### Tiling 不是 torch.compile / flash-attn

- VAE tiling 是 **应用层**的优化（在 Numpy/PyTorch 层面切分张量），不依赖底层 kernel 重写。
- torch.compile 是 **编译器层**优化（JIT 编译 + kernel fusion）。
- flash-attn 是 **算法层**优化（block-wise 计算，不物化 full attention matrix）。
- 三者在不同层面工作，可以叠加使用。但 VAE tiling 是最基础的显存控制手段。
